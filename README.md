# 🎯 osu! Personal Coach AI • CyberHUD Pro

Персональный локальный ИИ-тренер и интерактивный аналитический комплекс для игрока **tamik228_old_2** в **osu!lazer** с интеграцией Второй Памяти **Obsidian Vault**.

---

## ⚡ Главные возможности комплекса

1. **Мгновенный запуск в 1 клик:**
   - Просто дважды кликните по файлу **`Запустить_Тренера.bat`** в корне папки.
   - Сервер автоматически стартует на `http://127.0.0.1:8765` и сразу открывает браузер.
   - Не требуется Node.js, npm или скачивание гигабайтов `node_modules` — всё работает на чистом Python + современном фронтенде.

2. **⚡ Вкладка 1: HUD & Аналитика Реплеев:**
   - Чтение реальных реплеев (`.osr`) прямо из кэша osu!lazer (`AppData/Roaming/osu`).
   - Официальные данные игрока через **osu! API v2 Live** (Рейтинг, PP, Точность, Top Plays).
   - Распределение попаданий (Hit Window: 300 / 100 Early/Late / 50 / Miss).
   - Баланс пальцев **K1 / K2 Ratio** (выявление синглтап-доминирования и риска туннельного синдрома).
   - Радар ДНК навыков (Ритм, Аим мыши, Стамина, Стабильность).
   - **Индекс готовности к 5★** с прогнозом PP при выходе на 95%+ Acc.
   - Экспертная диагностика ошибок от ИИ-тренера с конкретными советами по фиксу.

3. **🎵 Вкладка 2: Интерактивный Ритм-Тренажёр (Разминка):**
   - Точный метроном на **Web Audio API** с настройкой любого темпа (120–230 BPM).
   - Полноценная поддержка клавиш **Z и X** (с возможностью переназначения).
   - Расчет **Unstable Rate (UR)** в реальном времени.
   - Визуальная шкала точности **Hit Error Bar** (-120ms Early / 0ms Perfect / +120ms Late) с моментальной фиксацией отклонения каждого клика в миллисекундах.
   - Кнопка **«Записать разминку в Obsidian»** для фиксации тренировочных сессий во Второй Памяти.

4. **🗺️ Вкладка 3: Каталог карт (Beatmap Hub):**
   - Коллекция верифицированных карт с разбивкой по навыкам:
     - 🎯 *Ритм и Early-Fix* (3.9★ – 4.3★)
     - 🖱️ *Аим мыши и Snap* (4.4★ – 4.7★)
     - ⚡ *Стамина и Берсты* (4.5★ – 4.9★)
     - 🌟 *Штурм 5★* (5.0★ – 5.3★)
   - Живой поиск по песням и артистам, бейджи сложности, BPM и прямые ссылки на скачивание.

5. **🧠 Вкладка 4: Вторая Память (Obsidian Second Brain):**
   - Встроенный в интерфейс просмотрщик всех заметок из папки `osu-vault/`.
   - Автоматическая двусторонняя синхронизация сыгранных карт в `06_Вторая_Память_Агента.md`.
   - Кнопка быстрого перехода в папку вольта.

6. **⚙️ Вкладка 5: Тюнинг & Настройки:**
   - Калькулятор чувствительности **eDPI** (DPI мыши × Сенса в osu!) с рекомендациями тренера.
   - Настройка кнопок тапа для ритм-тренажёра.

## 🚀 Быстрый старт

### Способ 1 (Самый простой — два клика):
Дважды нажмите на:
```text
Запустить_Тренера.bat
```
Откроется консоль сервера, а в вашем браузере сразу загрузится интерфейс **`http://127.0.0.1:8765`**.

### Способ 2 (Через терминал):
```bash
cd osu-trainer
python app.py
```
