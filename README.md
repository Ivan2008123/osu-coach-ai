# 🎯 osu! Personal Coach AI • CyberHUD Pro

Интерактивный ИИ-тренер и аналитический центр для игроков **osu!lazer**, ориентированный на выявление ошибок в механике (ранний тап / паника, баланс пальцев K1/K2, точность аима) и подготовку к стабильному прохождению карт **5★ на 90%+ аккураси**.

---

## ✨ Основные Возможности

1. **Автоматический захват реплеев из osu!lazer**:
   - Читает сырые реплеи `.osr` напрямую из внутреннего хранилища lazer (`files/`) без необходимости ручного экспорта.
2. **Интеграция с официальным osu! API v2**:
   - Синхронизация глобального рейтинга, текущего PP, точности и списка Top Plays в реальном времени.
3. **Глубокий анализ механики (Hit Window Precision & Finger Balance)**:
   - Раскладка идеальных попаданий (300) и неточностей (100 / 50).
   - Распределение нагрузки на клавиши K1 vs K2 для предупреждения *finger lock* и развития стамины.
   - Оценка готовности к 5★ картам (5-Star Readiness Gauge).
4. **Кураторский пул карт (Verified Beatmap Sets)**:
   - Прямые ссылки на проверенные классические карты от Sotarks, Kagetsu, Monstrata, Lami под конкретные дефициты (Ритм, Джамп-аим, Берсты, 5★ рубеж).
5. **Вторая Память (Obsidian Vault Integration)**:
   - Автоматическая запись каждого сыгранного скора в долгосрочный журнал `osu-vault/06_Вторая_Память_Агента.md` по стандарту Task Ledger и Hypothesis Ledger.

## 🚀 Быстрый Старт

### 1. Требования
- Python 3.10+
- Установленный [osu!lazer](https://osu.ppy.sh/home/download)

### 2. Установка зависимостей
```bash
pip install fastapi uvicorn osrparse ossapi requests
```

### 3. Запуск
Дважды кликните по файлу:
```cmd
osu-trainer/start_coach.bat
```
Или вручную из консоли:
```bash
cd osu-trainer
python app.py
```
Дашборд откроется в браузере по адресу: **`http://127.0.0.1:8765`**
