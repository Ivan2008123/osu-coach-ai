# 🤖 Персональный ИИ-Тренер (osu! Coach AI • CyberHUD Pro)

Для игрока **tamik228_old_2** развернут локальный аналитический комплекс на Python + FastAPI + Web Audio API с интеграцией официального `osu! API v2 Live` и поддержкой игры на **Графическом Планшете (ГП)**.

---

## ⚡ Как Запустить Тренер в 1 Клик
1. В корне репозитория просто дважды нажми:
   👉 **`Запустить_Тренера.bat`**
2. В браузере мгновенно откроется интерфейс: **http://127.0.0.1:8765**

---

## 🎯 Разделы и Возможности Комплекса:
1. **⚡ HUD & Аналитика Реплеев:** Автоматический захват игр из lazer (`AppData/Roaming/osu`), расчет попаданий (300 / 100 Early-Late / 50 / Miss), баланса пальцев K1/K2 и Индекса Готовности к 5★.
2. **🎵 Интерактивный Ритм-Тренажёр:** Web Audio метроном, расчет Unstable Rate (UR), визуальный Hit Error Bar и фиксация ранних тапов. Нажимай Z и X (или на любой раскладке клавиатуры) прямо в браузере.
3. **🗺️ Каталог Карт (Beatmap Hub):** Проверенные карты с разбивкой по навыкам (Ритм, Аим пера на ГП, Стамина, 5★ Рубеж) и живым поиском.
4. **🧠 Вторая Память (Obsidian):** Чтение и редактирование базы знаний прямо в интерфейсе, синхронизация сессий в `06_Вторая_Память_Агента.md`.
5. **⚙️ Тюнинг Графического Планшета (OTD):** Калькулятор активной области (Tablet Area), проверка пропорций 16:9, расчет диагонали и рекомендации под стили Drag и Hover.
