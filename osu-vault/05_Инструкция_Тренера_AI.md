# 🤖 Персональный ИИ-Тренер (osu! Coach AI)

Для тебя создано локальное интерактивное приложение-тренер на Python + FastAPI + Chart.js с поддержкой официального `osu! API v2`.

---

## ⚡ Как Запустить Тренер
1. Открой проводник и перейди в папку: `C:\Users\iples\Downloads\osu\osu-trainer`
2. Запусти файл `start_coach.bat`
3. В браузере откроется дашборд: **http://127.0.0.1:8765**

---

## 🎯 Что Умеет Тренер:
1. **Автоматический захват игр из lazer:** Тебе не нужно ничего экспортировать вручную. Сыграл песню → нажал кнопку `⚡ Синхронизировать с lazer` → получил мгновенный разбор.
2. **Индекс Готовности к 5★ (Readiness Gauge):** Показывает в реальном времени, насколько твоя мышечная память готова к 5★ картам.
3. **Анализ ошибок (Hit Window Precision):** Считает распределение 300, 100 и 50, подсказывая, где ты торопишься или чокаешь.
4. **Баланс Пальцев (K1 vs K2):** Показывает диаграмму нагрузки на каждый палец и предостерегает от *finger lock*.
5. **Подбор Карт под Дефициты:** Вешает неоновый бейдж `Тебе сюда!` на тот тренировочный пак, который сейчас нужнее всего.
